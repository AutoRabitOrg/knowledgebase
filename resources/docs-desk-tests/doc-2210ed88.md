### New features

#### API Security 2.0

**Description**

API Security 2.0 replaces Guard’s existing API Security module with updated checks for Salesforce External Client Apps and connected apps.

**Behavior**

The checks assess configurations across app access, credentials, network restrictions, and session security. Connected app checks also identify unverified apps and missing contact email addresses, with migration guidance available.

Guard does not migrate or replace connected apps. It uses Metadata API access to assess configurations and does not change app settings.

> **Action required:** To run all available checks, ensure the integration user has Metadata API access.

**Outcome**

Administrators can identify risky app configurations and use the findings and migration guidance to plan their next actions.
