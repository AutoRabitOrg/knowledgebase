# Global Settings

Global Settings holds the configuration that applies to the whole workspace: shared settings, saved sign-ins, the agents that run your jobs, your licence and IDE keys, the MCP connection for AI assistants and the email templates. Administrators use it to set up IZ Suite and keep it running.

Open it from **Administration** → **Global Settings** in the sidebar. Each screen is a tab along the top of the page.

<figure><img src="../../../../../.gitbook/assets/v2-gs-settings (1).png" alt="Global Settings with the Settings tab open"><figcaption><p>Global Settings tabs</p></figcaption></figure>

{% hint style="warning" %}
You see only the tabs your role allows. Most tabs need a role that can view global settings; **Saved sign-ins** also opens for roles that manage monitors, and **Agents** and **Connected systems** need a role that can view agents or systems.
{% endhint %}

## Screens in Global Settings

| Tab                   | Page                                      | What you do there                                                                          |
| --------------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------ |
| **Settings**          | [Settings](settings.md)                   | Browse, pin, create and edit the workspace settings and templates.                         |
| **Saved sign-ins**    | [Saved Sign-ins](saved-sign-ins.md)       | Store credentials once and reuse them in monitors and other settings.                      |
| **Agents**            | [Agents](agents.md)                       | Check agent contact, set their workers and job types, and start, stop or restart them.     |
| **Connected systems** | [Connected Systems](connected-systems.md) | Register systems and see which agents are assigned to them.                                |
| **Subscription**      | [Subscription](subscription.md)           | Check your licence status, the platforms it covers and how much of each allowance is used. |
| **IDE keys**          | [IDE Keys](ide-keys.md)                   | Assign the IDE extension keys from your licence to developers.                             |
| **MCP integration**   | [MCP Integration](mcp-integration.md)     | Copy the configuration that connects an AI assistant to IZ Suite.                          |
| **Email templates**   | [Email Templates](email-templates.md)     | Customize the HTML of the emails IZ Suite sends.                                           |
