# Enhanced Deployment Notes

### **Overview**

ARM enhances **Deployment Notes** to provide better visibility and accessibility during the deployment approval process.

Approvers can now review deployment notes through a dedicated, read-only **Deployment Notes** tab before approving or rejecting a deployment.

Additionally, URLs included in deployment notes are displayed as clickable links, and support for special characters has been improved.

### **1. Add Deployment Notes**

1. Initiate a new deployment in ARM.
2. Navigate to the **Deployment Settings** step.
3. Enter the relevant information in the **Deployment Notes** field, such as change request details, sign-off information, supporting documents, or reference URLs.
4. Proceed with the deployment submission.

![](<../../.gitbook/assets/image (687).png>)

### **2. View Deployment Notes During Approval**

Approvers can now access Deployment Notes directly from the deployment approval screen.

1. Open the deployment pending approval.
2. Navigate to the **Deployment Notes** tab, available alongside the **Components** and **Comments** tabs.
3. Review the notes and access any supporting links.
4. Proceed with approving or rejecting the deployment.

The Deployment Notes tab is **read-only**, ensuring that the information provided by the deployment initiator remains unchanged during the approval process.

### **3. Clickable Links in Deployment Notes**

URLs entered in Deployment Notes are automatically displayed as clickable links.

Users can access these links from:

* Deployment Approval screen.
* Deployment History.

Clicking a URL opens the corresponding page in a new browser tab, allowing users to access supporting information without navigating away from ARM.

### **4. Improved Special Character Support**

ARM now supports saving Deployment Notes containing common special characters and URLs without encountering previous saving errors.

Notes continue to be stored as plain text and displayed safely without executing embedded HTML.

### **Important Considerations**

* Deployment Notes are read-only on the approval screen.
* Existing Deployment Notes functionality remains unchanged.
* URLs automatically open in a new browser tab when clicked.
* No additional configuration is required to use these enhancements.

### **Benefits**

* Improved visibility of deployment information for approvers.
* Easy access to supporting documents and reference links.
* Improved collaboration between deployment initiators and approvers.
* More informed deployment approval decisions.
