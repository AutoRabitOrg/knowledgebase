# Select All Revisions in Release Labels (Classic UI)

**Product:** AutoRABIT ARM\
**Module:** Version Control – Release Labels\
**Availability:** Classic UI

### Overview

AutoRABIT ARM has enhanced the **Release Label creation and update workflow** in Classic UI by introducing a new **Select All** option.

This enhancement allows users to select or deselect all available revisions with a single click, eliminating the need to select each revision individually.

### What's New?

#### Select All Revisions

The following capabilities are now available when creating or updating Release Labels:

* **Select All:** Selects all available revisions in the list with a single click.
* **Deselect All:** Unchecking the Select All checkbox clears all selected revisions.
* **Individual Selection:** Users can continue to select or deselect specific revisions based on their requirements.
* **Create and Update Support:** The option is available when creating new Release Labels and editing existing ones.

### How to Use

1. Log in to AutoRABIT ARM using the **Classic UI**.
2. Navigate to **Version Control > Release Labels**.
3. Create a new Release Label or edit an existing one.
4. Complete the required Release Label configuration and navigate to the revision selection section.
5. Select the **Select All** checkbox to select all available revisions.
6. Uncheck **Select All** to clear the selection, or select and deselect individual revisions as needed.
7. Review the selected revisions and save the Release Label.

### Important Notes

* The Select All option is available for both creating and updating Release Labels.
* Unchecking Select All deselects all currently selected revisions.
* Users can continue to manage individual revision selections.
* The existing Release Label configuration and management process remains unchanged.
* This enhancement is supported in the **Classic UI**.

### Benefits

* Reduces manual effort when selecting multiple revisions.
* Simplifies Release Label creation and updates.
* Provides flexibility to manage revisions individually or in bulk.
