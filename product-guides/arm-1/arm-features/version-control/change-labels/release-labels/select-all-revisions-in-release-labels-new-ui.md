# Select All Revisions in Release Labels (New UI)

**Product:** AutoRABIT ARM\
**Module:** Version Control – Release Labels\
**Availability:** New UI

### Overview

AutoRABIT ARM has introduced a new **Select All** option in the **Release Label creation and update workflow** in the New UI.

With this enhancement, users can select or deselect all available revisions at once, making it easier to manage Release Labels containing multiple revisions.

### What's New?

#### Select All Revisions

The revision selection section now includes a **Select All** checkbox with the following capabilities:

* **Select All:** Automatically selects all available revisions in the list.
* **Deselect All:** Unchecking Select All deselects all selected revisions.
* **Individual Revision Selection:** Users can manually select or deselect individual revisions as required.
* **Create and Update Support:** The option is available when creating or updating Release Labels.

### How to Use

1. Log in to AutoRABIT ARM using the **New UI**.
2. Navigate to **Version Control > Release Labels**.
3. Click to create a new Release Label or edit an existing Release Label.

<figure><img src="../../../../../../.gitbook/assets/image (154).png" alt=""><figcaption></figcaption></figure>

4. Complete the required configuration details and navigate to the revision selection section.
5. Select the **Select All** checkbox to select all available revisions.

<figure><img src="../../../../../../.gitbook/assets/image (155).png" alt=""><figcaption></figcaption></figure>

6. Uncheck **Select All** to clear the selection, or manually adjust individual revision selections.

<figure><img src="../../../../../../.gitbook/assets/image (161).png" alt=""><figcaption></figcaption></figure>

7. Review the selected revisions and save the Release Label.

### Important Notes

* The Select All option is available during Release Label creation and updates.
* Users can select or deselect individual revisions even after using Select All.
* Unchecking Select All clears all selected revisions.
* Existing Release Label configuration options and functionality remain unchanged.
* This enhancement is supported in the **ARM New UI**.

### Benefits

* **Faster Revision Selection:** Selects multiple revisions with a single click.
* **Reduced Manual Effort:** Eliminates repetitive individual selections.
* **Greater Flexibility:** Supports both bulk and individual revision management.
* **Improved User Experience:** Simplifies Release Label creation and updates.
